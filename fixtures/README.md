# fixtures

Synthetic test media for the Task 1.1 thumbnail spike, generated by `gen.sh`.

Run `./gen.sh` from this directory (or from anywhere, it `cd`s to its own
location) to (re)generate:

- `sample.png` — 640x480 test pattern (ffmpeg `testsrc` lavfi source, 1 frame).
- `sample.jpg` — same test pattern, re-encoded as JPEG, then stamped with
  EXIF metadata via `exiftool` (`DateTimeOriginal`, `Model`, `LensModel`,
  `FNumber`, `ExposureTime`, `ISO`, `FocalLength`, GPS lat/long).
- `sample.heic` — `sample.jpg` converted to HEIC via macOS `sips`.
- `sample.mp4` — 2s H.264/yuv420p test clip (ffmpeg `testsrc` lavfi source).
- `sample.mov` — 2s ProRes (proxy profile, yuv422p10le) test clip. Uses the
  proxy profile instead of the default ProRes profile so the fixture stays
  well under 2 MB (default ProRes 422 produced a ~2.7 MB file for the same
  2s clip).

All fixtures are synthetic/generated and safe to commit.

## Optional: real RAW fixtures

If you have a real RAW file handy, you can drop it in this directory as:

- `sample.raf` (Fujifilm)
- `sample.cr3` (Canon)
- `sample.arw` (Sony)

These are user-supplied and **gitignored** (see root `.gitignore`) — they
are not required for the spike and are not committed. They're only useful
locally to test the `exiftool -b -PreviewImage` extraction path against a
real camera RAW preview.
